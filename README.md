# Awesome-No-Code-Integration-Platform

# Top No-Code Integration Platform Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Visual Workflow Automation, App Connectivity & Event-Driven Orchestration*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **No-Code Integration Platforms**. These tools let users connect apps, automate data flows, trigger actions across services, and build multi-step workflows through visual builders — without writing code — while offering connectors, triggers, transformations, and error handling.

**Examples** include Salesforce MuleSoft Composer, Zapier, Make, Workato Recipe Builder, Tray.io, Microsoft Power Automate, Pipedream, IFTTT Enterprise, Integrately, and Unito (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom connectors, and transparent workflow execution — ideal for developers, ops teams, and organizations building data-sovereign automation infrastructure.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Salesforce MuleSoft Composer](https://www.mulesoft.com/platform/composer)**  
  No-code integration tool within Salesforce for connecting apps and automating flows using prebuilt connectors.

- **[Zapier](https://zapier.com/)**  
  Leading no-code automation platform with 6,000+ app integrations, multi-step Zaps, and AI-powered workflow builder.

- **[Make](https://www.make.com/)**  
  Visual automation platform with scenario builder, routers, error handling, and 2,000+ app connectors.

- **[Workato Recipe Builder](https://www.workato.com/)**  
  Enterprise automation platform with low-code/no-code recipes, API management, and governance controls.

- **[Tray.io](https://tray.io/)**  
  Low-code automation platform with visual workflow builder, universal connectors, and enterprise-grade orchestration.

- **[Microsoft Power Automate](https://powerautomate.microsoft.com/)**  
  Microsoft's automation service with hundreds of connectors, desktop flows, and AI Builder integration.

- **[Pipedream](https://pipedream.com/)**  
  Developer-first integration platform with code + no-code steps, event sources, and 2,000+ APIs.

- **[IFTTT Enterprise](https://ifttt.com/enterprise)**  
  Simple automation platform connecting consumer and enterprise apps with applets and triggers.

- **[Integrately](https://integrately.com/)**  
  Affordable automation platform with 1-click integrations, multi-step workflows, and team collaboration.

- **[Unito](https://unito.io/)**  
  Two-way sync platform for project management and CRM tools with no-code workflow automation.

## Open-Source GitHub Projects

- **[n8n](https://github.com/n8n-io/n8n)**  
  Fair-code workflow automation platform with 400+ integrations, visual builder, custom code nodes, and self-hosting. The leading open-source alternative to Zapier and Make. Sustainable Use License.

- **[Node-RED](https://github.com/node-red/node-red)**  
  Flow-based programming tool for wiring together devices, APIs, and services. Massive node ecosystem, ideal for IoT and event-driven automation. Apache 2.0 licensed.

- **[Huginn](https://github.com/huginn/huginn)**  
  Open-source system for building agents that monitor and act on your behalf — web scraping, notifications, and event automation. MIT licensed.

- **[Activepieces](https://github.com/activepieces/activepieces)**  
  Open-source no-code automation tool with 200+ pieces (connectors), visual flow builder, and AI-friendly design. MIT licensed.

- **[Automatisch](https://github.com/automatisch/automatisch)**  
  Open-source business automation tool and Zapier alternative with self-hosting, workflows, and connector framework. AGPL-3.0 licensed.

- **[Windmill](https://github.com/windmill-labs/windmill)**  
  Open-source developer platform for building workflows, internal tools, and integrations from scripts (Python, TypeScript, Go, SQL). AGPL-3.0 licensed.

- **[Kestra](https://github.com/kestra-io/kestra)**  
  Open-source declarative orchestration and scheduling platform with YAML-based workflows, 500+ plugins, and event-driven triggers. Apache 2.0 licensed.

- **[Apache Airflow](https://github.com/apache/airflow)**  
  Industry-standard workflow orchestration platform with Python DAGs, rich operator ecosystem, and scheduling. Apache 2.0 licensed.

- **[Prefect](https://github.com/PrefectHQ/prefect)**  
  Modern workflow orchestration framework with Python-native flows, dynamic scheduling, and observability. Apache 2.0 licensed.

- **[Temporal](https://github.com/temporalio/temporal)**  
  Durable execution platform for building reliable workflows and microservices orchestration. MIT licensed.

- **[Camunda](https://github.com/camunda/camunda-bpm-platform)**  
  Open-source BPMN workflow and decision automation engine with visual modeling and execution. Apache 2.0 licensed.

- **[Apache NiFi](https://github.com/apache/nifi)**  
  Open-source data flow automation with visual programming, 300+ processors, and real-time routing. Apache 2.0 licensed.

- **[Apache Camel](https://github.com/apache/camel)**  
  Integration framework implementing Enterprise Integration Patterns with 300+ components. Apache 2.0 licensed.

- **[Benthos](https://github.com/redpanda-data/benthos)**  
  Open-source stream processing and integration tool with declarative config, 200+ connectors, and mapping language. MIT licensed.

- **[Logstash](https://github.com/elastic/logstash)**  
  Open-source data processing pipeline with input/filter/output plugins for ingesting and transforming events. Apache 2.0 licensed.

- **[Beehive](https://github.com/muesli/beehive)**  
  Flexible event/agent and automation system with modular architecture and community plugins. MIT licensed.

- **[Trigger.dev](https://github.com/triggerdotdev/trigger.dev)**  
  Open-source platform for building and deploying background jobs, workflows, and event-driven automations. Apache 2.0 licensed.

- **[Inngest](https://github.com/inngest/inngest)**  
  Open-source event-driven workflow engine with durable functions, step functions, and fan-out patterns. Apache 2.0 licensed.

- **[StackStorm](https://github.com/StackStorm/stacksorm)**  
  Open-source event-driven automation platform with sensors, triggers, actions, and rules engine. Apache 2.0 licensed.

- **[Rundeck](https://github.com/rundeck/rundeck)**  
  Open-source job scheduler and runbook automation with self-service workflows and access controls. Apache 2.0 licensed.

- **[Cronicle](https://github.com/jhuckaby/Cronicle)**  
  Open-source task scheduler and runner with real-time logs, plugins, and multi-server support. MIT licensed.

- **[Kubeflow Pipelines](https://github.com/kubeflow/pipelines)**  
  Open-source ML workflow orchestration with visual pipeline builder and reusable components. Apache 2.0 licensed.

- **[Joget](https://github.com/jogetworkflow/jw-community)** — Open-source low-code/no-code platform with workflow engine, forms, and integration APIs.
- **[ProcessMaker](https://github.com/processmaker/processmaker)** — Open-source BPM and workflow automation with visual designer and API integrations.
- **[Flowable](https://github.com/flowable/flowable-engine)** — Open-source BPMN and CMMN engine for workflow and case management automation.
- **[Bonita](https://github.com/bonitasoft/bonita-engine)** — Open-source BPM platform with visual process modeling and connector framework.
- **[Corteza](https://github.com/cortezaproject/corteza)** — Open-source low-code platform with workflow automation, CRM, and integration capabilities.
- **Message Queues** (RabbitMQ, Apache Kafka, Redis Streams, NATS) for event-driven integration backbones.
- **API Gateways** (Kong, Tyk, KrakenD) for exposing and orchestrating service integrations.

**Frameworks for building custom systems**: Combine **n8n** for no-code workflows, **Node-RED** for event-driven IoT flows, **Temporal** for durable orchestration, **Apache NiFi** for data pipelines, and **PostgreSQL + Metabase** for workflow analytics to build a complete self-hosted integration platform.
